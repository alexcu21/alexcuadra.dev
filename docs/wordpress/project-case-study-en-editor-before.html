Role: Frontend Developer (Contractor)

Tech Stack: WordPress Block Editor (Gutenberg), React, Svelte, Advanced Custom Fields (ACF Pro), WordPress REST API, Modern CSS / SCSS

Overview

Engineered a custom, production-ready block suite for Christianity Today’s digital publishing platform, translating complex, high-fidelity design specifications into flexible, reusable editorial components within the WordPress block editor.

The Challenge

The publication required a modern editorial toolkit to create rich, visually sophisticated long-form stories and landing pages. The core objective was achieving pixel-perfect fidelity with strict Figma design systems while keeping the editing experience intuitive, performant, and resilient against layout breakage across different viewports.

The Solution

Operating as an external frontend contractor, I developed custom blocks leveraging React, Svelte, and ACF Pro integrated with the WordPress Block API. I established modular styling architectures and strict component props to enforce design tokens (typography, spacing, responsive grid behaviors) directly in the editor canvas, providing content creators with a true WYSIWYG experience that mirrored frontend output with zero layout drift.

Key Highlights

  • Pixel-Perfect Execution: Translated intricate editorial design systems into responsive, fluid components matching design specifications down to exact spacing and typography scales.
  • Hybrid Modern Architecture: Combined the power of React and lightweight Svelte components with the WordPress Block API to ensure optimal editor performance and clean, decoupled frontend markup.
  • Streamlined Content Authoring: Empowered editorial teams to assemble dynamic layouts independently while programmatically safeguarding brand consistency and layout integrity.
  • Seamless Theme Integration: Built modular, decoupled components engineered to integrate cleanly into the client’s existing WordPress theme architecture and deployment pipeline.
