# Editorial Proposals 0.1.0-rc.2

Candidato para revisión, **HOLD: no instalar todavía**. Derivado de las seis operaciones de propuestas de Editorial Changes0.5-lab; el laboratorio se conserva intacto. No incluye reviews.php ni applications.php, aprobación, apply/recover ni APIs de escritura de Projects. `restore-project-change-revision` restaura únicamente el patch de una propuesta privada.

Guard cerrado por defecto: requiere constante `AC_EDITORIAL_PROPOSALS_SITE` con valor exacto `https://content.alexcuadra.dev`, home_url y site_url iguales a ese valor, single site y laboratorio inactivo. La constante no se configura en este incremento. No tiene bypass de laboratorio, rutas de administración, cron, activación con efectos ni uninstall.

Seis abilities `alexcuadra/`: create-project-change, get-project-change, update-project-change, list-project-change-revisions, get-project-change-revision y restore-project-change-revision. El contrato de entrada y el patch body_html/tagline se conservan. DTO siempre draft/applied=false; nunca se aplica al origen. Historial hasta32 revisiones/2MiB, cuotas por dueño8 propuestas/128 solicitudes únicas/8MiB lógicos incluyendo recibos. Reintentos requieren misma request_id y parámetros. No TTL, poda, borrado automático ni rebase; cuota llena rechaza nuevas escrituras.

Almacenamiento separado: CPT `ac_private_proposal`, meta `_ac_private_proposal_payload`, tablas con prefijo WordPress `ac_proposal_owners` y `ac_proposal_requests`, opción `ac_proposals_storage_version`. No migra ni reutiliza propuestas, recibos, eventos o aprobaciones de laboratorio. Es una adición al esquema del CMS, no un downgrade0.5. No toca las tablas anteriores.

La carga registra el CPT privado y las seis abilities pero no crea tablas. `install_storage()` solo admite WP-CLI con manage_options y debe invocarse explícitamente durante una futura instalación aprobada. Rechaza transacciones externas para evitar commits implícitos de DDL. Antes de crear y después de crear valida columnas/orden/tipos/unsigned/null/default/extra/collation, claves primarias exactas sin índices adicionales, motor/base table, constraints, triggers visibles y particiones. No confía en un marcador0.1 anterior. Un fallo de validación retira el marcador de disponibilidad; no altera ni borra tablas/datos incompatibles. LONGTEXT de respuesta usa explícitamente utf8mb4_bin. Esta revisión del esquema no certifica semántica de recibos preexistentes ni privilegios para ver triggers ocultos. CREATE IF NOT EXISTS puede dejar tablas vacías parciales si falla una creación; no se borran automáticamente. Las operaciones requieren opción0.1 y verifican cuatro motores InnoDB/transacción no anidada. No hay dbDelta, ALTER ni reparación automática. La comprobación exhaustiva ocurre durante la preparación explícita; no es vigilancia continua de cambios de un administrador de DB. rc.1 se conserva como artefacto histórico y no debe instalarse.

Permisos para operar: login + read + alexcuadra_read_public_projects + alexcuadra_prepare_project_changes. No concede ninguno, no cambia roles, no exige Editor; manage_options solo corresponde al operador CLI de preparación de tablas. Usuario2 conserva solo lectura hasta autorización específica. Administrador sin scopes también es denegado. No incluye scopes apply/recover/approve.

Privacidad de aplicación: CPT sin UI/REST/GraphQL/consulta pública; solo dueño mediante abilities. No devuelve cuerpo/meta original, solo huella, patch y metadatos de propuesta. Datos privados en DB, recibos y backups no equivalen a almacenamiento cifrado. Administrador de DB/hosting puede leerlos. Tratar todo patch como contenido no confiable.

Rollback: detener admisiones retirando la constante o desactivando únicamente este plugin; retirar únicamente el scope prepare si se concedió; conservar Read, tablas y propuestas. Desactivación no elimina datos. Este candidato nunca aplica fuentes, de modo que no existe recuperación de Projects asociada. No ejecutar uninstall ni restaurar toda la DB compartida para retirar el módulo.

Pruebas locales de frontera con stubs PHP: no certifican WordPress, ACF/Polylang, privacidad HTTP/GraphQL, cuotas reales, concurrencia ni restauración. Antes de instalar: ensayo aislado de esas rutas y esquema exacto, backup restaurado, archivo privado verificable, responsable/retención acordados y aprobación concreta del paquete+scope. No heredar retención del formulario de contacto. Ver `docs/WORDPRESS_MCP_PROPOSALS_CANDIDATE.md` en el repositorio.
